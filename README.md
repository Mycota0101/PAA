# BFS Shortest Path Finder

Proyek ini mengimplementasikan algoritma **Breadth-First Search (BFS)** untuk menemukan jalur terpendek di sebuah labirin, dengan antarmuka visual menggunakan **Pygame**.

## 📌 Fitur
- Penentuan titik awal, akhir, dan penghalang secara interaktif.
- Visualisasi real-time proses BFS.
- Kontrol sederhana dengan mouse dan keyboard.
- Grid 30x30 dengan kode warna:
  - 🔵 Start
  - 🟡 End
  - ⚫ Barrier
  - 🟢 Open nodes
  - 🔴 Closed nodes
  - 🟦 Jalur akhir

## ▶ Cara Menjalankan
Pastikan Python dan Pygame sudah terinstal, lalu jalankan:
```bash
python labirin.py
